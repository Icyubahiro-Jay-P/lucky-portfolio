# Contributing to Lucky Portfolio

Thank you for considering contributing to **Lucky - Nisingizwe Lucky Junior Portfolio**!

## Getting Started

1. Fork the repo and clone: `git clone https://github.com/Icyubahiro-Jay-P/lucky-portfolio.git`
2. Install: `npm install`
3. Run dev: `npm run dev`
4. Build: `npm run build` and `npm run preview`
5. Lint: `npm run lint`

## Tech Stack

- React 19 + Vite 8
- Tailwind CSS 4 via @tailwindcss/vite
- Liquid Glass via @ybouane/liquidglass
- Lucide React icons

## Project Structure

- `src/App.jsx` - flat root with SystemBackground
- `src/components/` - Nav, Hero, About, Skills, Projects, etc.
- `src/hooks/useLiquidGlass.js`
- `src/data/content.js` - person, skills, projects, education

## How to Contribute

1. Create a branch: `git checkout -b feat/your-feature`
2. Make changes, keep LiquidGlass flat-root layout intact
3. Ensure `npm run lint` and `npm run build` pass
4. Commit with conventional messages: `feat:`, `fix:`, `chore:`
5. Open a pull request against `main` with description and screenshots if UI

## Code Style

- ESLint with react-hooks and react-refresh plugins
- Keep components accessible and motion-reduced friendly
- No secrets in commits

## Reporting Issues

Use GitHub Issues with clear reproduction steps.

## Code of Conduct

By participating, you agree to abide by our Code of Conduct.
